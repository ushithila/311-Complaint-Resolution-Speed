## 🏗️ **Project Overview**

This project is  focused on applying machine learning and agentic AI to a real-world civic data problem.

Every day, thousands of complaints are filed through New York City's 311 platform, covering issues ranging from illegal parking to apartment maintenance problems. While the City publishes service level agreements (SLAs) stating the maximum time agencies commit to for resolving each complaint type, these targets are static, generic, and don't reflect actual, location- or time-specific outcomes. Residents currently have no reliable way to know how long a complaint like theirs will realistically take.

This project addresses that gap by building a machine learning model that predicts 311 complaint resolution time based on real historical data, and an AI agent that lets users ask open-ended questions about resolution patterns (e.g., comparing boroughs or complaint types) in natural language. The goal is to give residents realistic, data-grounded expectations, and to surface systemic disparities in city responsiveness that could be useful to researchers, journalists, and community stakeholders.
